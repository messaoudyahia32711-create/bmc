   102→                  <span className={chk.done ? 'text-ok' : 'text-muted-foreground/50'}>{chk.done ? '✓' : '○'}</span>

   121→            <span>{t.privacyLines[1]} {t.privacyLines[2]}</span>
   122→          </div>
   123→        </aside>
   124→      </div>
   125→
   126→      {/* footer nav */}
   127→      <div className="mt-6 flex items-center justify-between border-t border-border/60 pt-4">
   128→        <Button variant="outline" disabled={step === 0} onClick={() => setStep(s => s - 1)} className="gap-1">
   129→          {lang === 'ar' ? <><ChevronRight className="h-4 w-4" />{t.prev}</> : <><ChevronLeft className="h-4 w-4" />{t.prev}</>}

   261→function ProductCard({ prod, p, update, idx, hint }: { prod: Product; p: Project; update: (fn: (d: Project) => void) => void; idx: number; hint: string }) {
   262→  const { t, lang } = useApp();
   263→  const set = (fn: (x: Product) => void) => update(d => fn(d.products[idx]));
   264→  const ue = (() => {
   265→    if (prod.model === 'fixed') return { margin: prod.price - prod.variable, rate: prod.price > 0 ? (prod.price - prod.variable) / prod.price : 0, rev: prod.price * prod.qty, mrev: (prod.price - prod.variable) * prod.qty };
   266→    if (prod.model === 'commission') return { margin: prod.deal * prod.commission / 100 - prod.dealCost, rate: prod.deal * prod.commission / 100 > 0 ? (prod.deal * prod.commission / 100 - prod.dealCost) / (prod.deal * prod.commission / 100) : 0, rev: prod.deal * (prod.commission / 100) * prod.deals, mrev: (prod.deal * prod.commission / 100 - prod.dealCost) * prod.deals };
   267→    return { margin: prod.sub - prod.subCost, rate: prod.sub > 0 ? (prod.sub - prod.subCost) / prod.sub : 0, rev: prod.sub * prod.subs, mrev: (prod.sub - prod.subCost) * prod.subs };
   268→  })();
   269→  const money = (n: number) => fmtMoney(n, lang);
   270→  return (
   271→    <div className="rounded-xl border border-border/70 bg-white/60 dark:bg-card p-4">
   272→      <div className="grid gap-3.5 sm:grid-cols-4">
   273→        <TextField label={t.productName} value={prod.name} onChange={v => set(x => { x.name = v; })} />
   274→        <Field label={t.revenueModel}>
   275→          <Select value={prod.model} onValueChange={v => set(x => { x.model = v as Product['model']; })}>
   276→            <SelectTrigger className="bg-white/80 dark:bg-card"><SelectValue /></SelectTrigger>
   277→            <SelectContent>
   278→              <SelectItem value="fixed">{t.rmFixed}</SelectItem>
   279→              <SelectItem value="commission">{t.rmCommission}</SelectItem>
   280→              <SelectItem value="subscription">{t.rmSubscription}</SelectItem>
   281→            </SelectContent>
   282→          </Select>
   283→        </Field>
   284→        <Field label={t.category}>
   285→          <Select value={prod.category} onValueChange={v => set(x => { x.category = v as Product['category']; })}>
   286→            <SelectTrigger className="bg-white/80 dark:bg-card"><SelectValue /></SelectTrigger>
   287→            <SelectContent>
   288→              <SelectItem value="service">{t.catService}</SelectItem>
   289→              <SelectItem value="trade">{t.catTrade}</SelectItem>
   290→              <SelectItem value="industrial">{t.catIndustrial}</SelectItem>
   291→              <SelectItem value="digital">{t.catDigital}</SelectItem>
   292→            </SelectContent>
   293→          </Select>
   294→        </Field>
   295→        <div className="flex items-end">
   296→          <Button size="sm" variant="ghost" className="gap-1 text-destructive hover:text-destructive" onClick={() => update(d => { d.products = d.products.filter(x => x.id !== prod.id); if (!d.products.length) d.products.push(newProduct()); })}>
   297→            <Trash2 className="h-3.5 w-3.5" />{t.delProduct}
   298→          </Button>
   299→        </div>
   300→      </div>
   301→      {prod.model === 'fixed' && (
   302→        <div className="mt-3 grid gap-3.5 sm:grid-cols-4">
   303→          <NumField label={t.pPrice} value={prod.price} onChange={v => set(x => { x.price = v; })} />
   304→          <NumField label={t.pVariable} value={prod.variable} onChange={v => set(x => { x.variable = v; })} />
   305→          <NumField label={t.pQty} value={prod.qty} onChange={v => set(x => { x.qty = v; })} />
   306→          <NumField label={t.pGrowth} value={prod.growth} onChange={v => set(x => { x.growth = v; })} />
   307→        </div>
   308→      )}
   309→      {prod.model === 'commission' && (
   310→        <div className="mt-3 grid gap-3.5 sm:grid-cols-4">
   311→          <NumField label={t.pDeal} value={prod.deal} onChange={v => set(x => { x.deal = v; })} />
   312→          <NumField label={t.pCommission} value={prod.commission} onChange={v => set(x => { x.commission = v; })} />
   313→          <NumField label={t.pDeals} value={prod.deals} onChange={v => set(x => { x.deals = v; })} />
   314→          <NumField label={t.pDealCost} value={prod.dealCost} onChange={v => set(x => { x.dealCost = v; })} />
   315→        </div>
   316→      )}
   317→      {prod.model === 'subscription' && (
   318→        <div className="mt-3 grid gap-3.5 sm:grid-cols-4">
   319→          <NumField label={t.pSub} value={prod.sub} onChange={v => set(x => { x.sub = v; })} />
   320→          <NumField label={t.pSubs} value={prod.subs} onChange={v => set(x => { x.subs = v; })} />
   321→          <NumField label={t.pSubGrowth} value={prod.subGrowth} onChange={v => set(x => { x.subGrowth = v; })} />
   322→          <NumField label={t.pSubCost} value={prod.subCost} onChange={v => set(x => { x.subCost = v; })} />
   323→        </div>
   324→      )}
   325→      <div className="mt-3 flex flex-wrap items-center gap-2">
   326→        <AlertCalm tone="ok"><span className="text-[12px]">{hint}</span></AlertCalm>
   327→        {prod.model === 'fixed' && prod.price > 0 && prod.price <= prod.variable && <AlertCalm tone="bad"><span className="text-[12px]">⚠ {t.warnPriceBelowCost}</span></AlertCalm>}
   328→        {prod.model === 'fixed' && prod.qty <= 0 && prod.price > 0 && <AlertCalm tone="warn"><span className="text-[12px]">⚠ {t.warnQtyZero}</span></AlertCalm>}
   329→      </div>
   330→      <div className="mt-3 grid grid-cols-2 gap-2 sm:grid-cols-4">
   331→        <KpiCard label={t.ueMargin} value={money(ue.margin)} />
   332→        <KpiCard label={t.ueMarginRate} value={`${(ue.rate * 100).toFixed(1)}%`} tone={ue.rate >= 0.3 ? 'ok' : ue.rate >= 0.15 ? 'warn' : 'bad'} />
   333→        <KpiCard label={t.ueMonthlyRev} value={money(ue.rev)} />
   334→        <KpiCard label={t.ueMonthlyMargin} value={money(ue.mrev)} tone={ue.mrev > 0 ? 'ok' : 'bad'} />
   335→      </div>
   336→    </div>
   337→  );

   690→function swotSuggestions(p: Project, t: Dict): { strengths: string[]; weaknesses: string[]; opportunities: string[]; threats: string[] } {
   691→  const snap = computeSnapshot(p);
   692→  const marginRate = snap.base.rev > 0 ? (snap.base.rev - snap.base.varCost) / snap.base.rev : 0;
   693→  const ar = t.dir === 'rtl';
   694→  const s: { strengths: string[]; weaknesses: string[]; opportunities: string[]; threats: string[] } = {
   695→    strengths: [], weaknesses: [], opportunities: [], threats: [],
   696→  };
   697→  if (marginRate >= 0.3) s.strengths.push(ar ? 'هامش ربح إجمالي مرتفع يسمح بالمنافسة بالسعر' : 'Marge brute élevée permettant de jouer sur les prix');
   698→  if (p.products.length > 1) s.strengths.push(ar ? 'تنويع في المنتجات/الخدمات يقلل مخاطر الإيراد' : 'Diversification des produits réduisant le risque de revenus');
   699→  if (p.funding.selfPercent >= 30) s.strengths.push(ar ? 'مساهمة شخصية مريحة تعكس الالتزام أمام الممولين' : 'Apport personnel confortable, gage d’engagement');
   700→  if (marginRate > 0 && marginRate < 0.25) s.weaknesses.push(ar ? 'هامش ربح منخفض يحدد القدرة على التغطية' : 'Marge faible limitant la capacité de couverture');
   701→  if (snap.fixed > snap.base.rev * 0.5 && snap.base.rev > 0) s.weaknesses.push(ar ? 'تكاليف ثابتة مرتفعة مقارنة برقم الأعمال' : 'Charges fixes élevées par rapport au CA');
   702→  if (snap.loanShare > 0.6) s.weaknesses.push(ar ? 'اعتماد كبير على القرض يرفع المخاطر المالية' : 'Forte dépendance au prêt augmentant le risque financier');
   703→  if (!p.market.competitors.length) s.weaknesses.push(ar ? 'دراسة المنافسة غير مكتملة بعد' : 'Analyse de la concurrence non finalisée');
   704→  s.opportunities.push(ar ? 'برامج الدعم الجزائرية (ANADE، النواشئ…) قابلة للاستثمار في النمو' : 'Dispositifs algériens d’appui mobilisables pour la croissance');
   705→  if (p.info.wilaya) s.opportunities.push(ar ? `توسيع الطلب محلياً في ${p.info.wilaya} عبر الشراكات` : 'Expansion de la demande locale via des partenariats');
   706→  s.threats.push(ar ? 'ارتفاع أسعار المدخلات (مواد أولية، طاقة، نقل)' : 'Hausse des coûts des intrants (matières, énergie, transport)');
   707→  if (p.type.types.includes('commercial')) s.threats.push(ar ? 'دخول منافس جديد قريب بنفس العرض' : 'Arrivée d’un concurrent proche avec la même offre');
   708→  if (p.funding.hasLoan === 'yes') s.threats.push(ar ? 'ضغط سداد القرض في الأشهر الأولى الضعيفة' : 'Pression du remboursement durant les premiers mois faibles');
   709→  return s;
   710→}
